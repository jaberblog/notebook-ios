# دفترچه یادداشت — Evelyn Notebook (iOS)

یک نوت‌بوک ساده با **SwiftUI** (سوئیفت) برای آیفون و آیپد.
رابط فارسی و راست‌به‌چپ، تاریخ شمسی، جستجو، و ذخیره‌ی خودکار روی گوشی.

## چی دارد

- لیست یادداشت‌ها، مرتب بر اساس آخرین ویرایش
- یادداشت جدید با دکمه‌ی `+`
- ویرایش عنوان و متن (ذخیره‌ی خودکار هنگام تایپ)
- حذف با کشیدن به چپ، یا با دکمه‌ی سطل آشغال در صفحه‌ی ویرایش
- جستجو در عنوان و متن
- تاریخ شمسی برای هر یادداشت + شمارش کاراکتر
- ذخیره‌سازی محلی در فایل `notes.json` داخل Documents گوشی — بدون سرور و بدون حساب کاربری

## مشخصات فنی

- زبان: Swift 5 / SwiftUI
- حداقل iOS: ‏16.0
- Bundle ID: ‏`com.evelyn.notebook`
- نام اپ: EvelynNotebook — نسخه 1.0

## باز کردن در Xcode

1. این پوشه را در Xcode باز کنید: فایل `EvelynNotebook.xcodeproj`
2. یک آیفون (یا شبیه‌ساز) را انتخاب کنید و Run را بزنید.
3. برای اجرا روی آیفون واقعی با اپل‌آیدی رایگان: در Xcode به
   `Settings → Accounts` اپل‌آیدی خود را اضافه کنید، بعد در تنظیمات
   Target قسمت Signing، تیم خود را انتخاب کنید. این روش ۷ روز اعتبار
   دارد و هر هفته باید دوباره نصب شود.

## گرفتن خروجی IPA با گیت‌هاب

1. یک مخزن (Repository) در گیت‌هاب بسازید و محتوای این پوشه را در آن push کنید.
2. به تب **Actions** بروید — ورک‌فلوی **Build IPA** با هر push روی `main`
   یا با اجرای دستی (Run workflow) اجرا می‌شود.
3. وقتی سبز شد، از پایین همان صفحه‌ی اجرا، فایل **EvelynNotebook-ipa**
   را دانلود کنید. داخل آن فایل `EvelynNotebook.ipa` است.

## ⚠️ نکته‌ی مهم درباره‌ی نصب IPA

IPAای که این ورک‌فلو می‌سازد **بدون امضاست (unsigned)** و به همین دلیل
مستقیم روی آیفون نصب نمی‌شود. گیت‌هاب بدون دسترسی به سرتیفیکیت و
پروویژن پروفایل شما نمی‌تواند IPA قابل‌نصب مستقیم بسازد. سه راه دارید:

### ۱) نصب با AltStore یا Sideloadly (بدون حساب پولی)
- فایل IPA را با **AltStore** یا **Sideloadly** و با اپل‌آیدی رایگان خودتان
  امضا و نصب کنید. ۷ روز اعتبار دارد و هر هفته باید تمدید شود.
- این روش برای یک اپ معمولی مثل دفترچه یادداشت کار می‌کند.

### ۲) حساب دولوپر اپل (سالی ۹۹ دلار) — IPA قابل‌نصب مستقیم
- اگر حساب پولی دولوپر دارید، فایل
  `.github/workflows/build-ipa-signed.yml.example` را به
  `build-ipa-signed.yml` تغییر نام دهید.
- در گیت‌هاب، در `Settings → Secrets and variables → Actions` این
  Secretها را بگذارید:
  - `BUILD_CERTIFICATE_BASE64` — فایل `.p12` سرتیفیکیت Distribution، به صورت Base64
  - `P12_PASSWORD` — رمز فایل `.p12`
  - `BUILD_PROVISION_PROFILE_BASE64` — فایل `.mobileprovision`، به صورت Base64
  - `KEYCHAIN_PASSWORD` — یک رمز دلخواه برای کی‌چین موقت
- بعد ورک‌فلوی امضادار، IPA امضاشده و قابل‌نصب می‌سازد.

### ۳) نصب مستقیم از Xcode
- پروژه را در Xcode باز کنید و با کابل یا وای‌فای روی آیفون خودتان Run کنید.
  با اپل‌آیدی رایگان هم کار می‌کند (۷ روزه).

## ساختار پروژه

```
EvelynNotebook.xcodeproj/     پروژه‌ی Xcode
EvelynNotebook/
  EvelynNotebookApp.swift     نقطه‌ی ورود اپ
  Models/
    Note.swift                مدل یادداشت + تاریخ شمسی
    NotesStore.swift          ذخیره و بارگذاری JSON
  Views/
    ContentView.swift         لیست + جستجو
    NoteEditorView.swift      صفحه‌ی ویرایش
  Assets.xcassets/            آیکون و رنگ اصلی
.github/workflows/
  build-ipa.yml               ساخت IPA بدون امضا در گیت‌هاب
  build-ipa-signed.yml.example  ساخت IPA امضاشده (با حساب دولوپر)
```
